
# Calculadora Simples em Python

## Descrição do Projeto

Este projeto consiste em uma calculadora simples desenvolvida
em Python. O programa permite realizar operações matemáticas
básicas por meio de informações digitadas pelo usuário.

A atividade tem como objetivo praticar conceitos fundamentais
da programação, como variáveis, entrada de dados, estruturas
condicionais, funções e tratamento de erros.

## Funcionalidades

- Adição de dois números.
- Subtração de dois números.
- Multiplicação de dois números.
- Divisão de dois números.
- Validação de entradas numéricas.
- Tratamento de divisão por zero.
- Mensagem de erro para operações inválidas.

## Tecnologias Utilizadas

- Python 3
- GitHub para hospedagem do código.
- Markdown para documentação do projeto.

## Como Executar

1. Instale o Python 3 em seu computador.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta onde está o arquivo script.py.
4. Execute o comando:

   python script.py

Se o comando acima não funcionar, tente:

   python3 script.py

5. Siga as instruções exibidas no terminal.

## Exemplo de Uso

O programa solicita dois números e a operação desejada.

Exemplo:

Primeiro número: 10
Segundo número: 5
Operação: 1

Resultado: 15.0

## Conceitos de Programação Aplicados

- Variáveis para armazenar os números e a operação.
- Função para organizar a execução da calculadora.
- Estruturas condicionais para selecionar a operação.
- Entrada e saída de dados com input() e print().
- Tratamento de erros com try e except.
